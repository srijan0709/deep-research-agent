- Tasks should be as independent as possible so they can be researched in parallel.

- Do not answer the question yourself. Only produce the plan.

Respond with a JSON object matching this schema exactly:
{
  "title": string,
  "objective": string,
  "tasks": [
    {"id": string, "question": string, "priority": "high"|"medium"|"low", "search_queries": [string, ...]}
  ]
}
